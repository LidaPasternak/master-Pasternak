Автор: Пастернак Лідія Юріївна

Науковий керівник: Калініна І.О., д.т.н., професор

Короткий опис: Цей проект складається з моделі машинного навчання для прогнозування витрат пального (training.py), API-сервера на базі FastAPI (api.py) та веб-інтерфейсу (HTML/JS/CSS).

Інструкція:
1. Для роботи проекту потрібен Python версії 3.7+
2. Потрібно встановити бібліотеки:
`pip install fastapi uvicorn pandas scikit-learn numpy`
3. (Опціонально) Запустити файл з тренуванням:
`python training.py`
4. Запустити веб-сервер:
`uvicorn api:app --reload`
5. Перейти за адресою http://127.0.0.1:8000
